## 三、建议的检查路线（约 15 分钟）

1. **首页 / 任务页**：用 `demo001`（密码 `demo12345`）登录 → 打开「图像去噪」，能看到两张输入图（D01 真实噪声、D02 合成噪声）、当前指标说明、提交记录表。
2. **上传一张结果图**：直接拖本地任意同尺寸 PNG 上传，立刻出 PSNR / SSIM。不限次数，可以连传几张比较。
3. **最终确认**：提交记录里点「确认为最终作品」，注意下拉框**默认选中该图指标最好的那次**（带 ★），如果已确认的不是最优会黄字提示。确认后上方出现「已确认记录」，写明 图片 · 文件名 · 提交时间 · 确认时间。
4. **排行榜**：`/leaderboard/`，五个榜（去噪客观 / 去噪主观 / 去色客观 / 去色主观 / 综合·主观）。表头有「排名依据」「同分依据」标注——去噪按两图平均 PSNR，同分比 SSIM；去色按平均 E-score，同分比 CCPR；两张主观榜写明由 Bradley–Terry 拟合、每人多少份；**综合·主观**把两张主观榜按权重（默认各 50%）合成一个总分，只有两项都有主观分的才入榜，单项的列在「未纳入综合排名」。
5. **教师面板** `/staff/`：
   - 「匿名互评 · 份数与分配」：**两个任务分别填每人份数**，保存后按任务分配；旁边能看到每个任务的作品数、已分配、已投票与覆盖率。
   - 「学生注册」：只有一个「开放自助注册」开关，学生用学号自建账号后即可使用（无邀请码、不限学号前缀、不需审核、不强制改密）。
   - 上线验收灯、「重算排名（客观 + 主观）」（一次写好客观名次并重拟合 BT）、成绩与作品导出。
6. **管理后台** `/admin/`：学生档案、提交预览与重新评分、运行设置（临时改赛程 / 排行榜开关 / 去色综合分权重 / 各任务互评份数）、导出 CSV / 最终作品 ZIP。「客观排名」「主观排名」两张快照表可直接查名次——客观排名列出名次 / 参赛编号 / 姓名 / 排名指标 / 指标均值 / 并列指标 / 计算时间，可按任务与指标筛选、按编号搜索；它随学生确认作品、教师改最终标记或重新评分自动重算，也可用下拉动作「按当前指标重算客观排名」手动刷新。
7. **注册系统**：目前是**开放**状态，登录页有「用学号注册」入口。想临时关闭就在教师面板「学生注册」取消勾选并保存；关闭后 `/register/` 显示「暂未开放」。
8. **互评模块**：赛程已被设为「提交已截止、互评进行中（12-04 13:39 截止）」，直接用 `demo001`–`demo010` 登录就能看到待评题目（它们故意没投票）。页面版式为：上方居中显示输入图（含噪图 / 彩色原图），下方并排两张结果图（点图即可选中），再下面是「请选择更合理的……」单选列表与灰色「评价依据」提示框；也可按 `A` / `B` 直接选中、`Enter` 提交。看完想恢复 yaml 的真实赛程，在后台「运行设置」把四个时间字段清空即可。

## 四、实现要点（对应代码位置）

| 关注点 | 文件 |
|---|---|
| 竞赛规则 / 任务 / 赛程（唯一事实来源） | `config/competition.yaml` |
| **学术参数**（PSNR 动态范围、SSIM 窗口、去色 τ / 采样轮数 / 种子、裁切尺寸、合成噪声 σ） | `competition/research/params.py`（唯一默认值；yaml 的 `metrics_options` 可覆盖，改完不用重启） |
| **退化算子**（高斯加噪 `Y = clip(X + N(0,σ²),0,255)`、按梯度能量选纹理区裁切） | `competition/research/degradation.py` |
| **每张图的输入图 / 参考图 / 退化声明** | `config/competition.yaml` 的 `images[].degradation`（`real` / `gaussian` / `none`），解析在 `competition/research/dataset.py` |
| **任务 → 指标族**（谁用 PSNR/SSIM、谁用 CCPR/CCFR/E） | `competition/research/evaluators.py`，按任务的 `evaluator` 字段显式分派 |
| 数据源定位与配对（SIDD / CADIK） | `competition/research/sources.py` |
| 指标数学实现 | `competition/metrics/denoise.py`、`competition/metrics/decolor.py`（IJCV14 `metric.m` 的 Python 移植，τ=5，每像素 10 对像素，种子固定 20140101） |
| 客观排名 | `competition/services/leaderboard.py` 的 `objective_rows()`（实时计算）/ `refresh_objective()`（后台快照） |
| 主观排名 | `competition/peer_review/ranking.py`（Bradley–Terry，MM 迭代 + L2 正则） |
| 互评分配 | `competition/peer_review/allocation.py`（不评自己、不重复、覆盖均衡） |
| 双任务互评 | `competition/services/reviews.py`（按任务取份数、分配、进度）、`config/competition.yaml` 的 `peer_review.tasks` |
| 自助注册 | `competition/services/registration.py`（校验/编号）、`competition/views/auth.py` 的 `register_view` |
| 综合主观榜 | `competition/services/leaderboard.py` 的 `combined_subjective_rows()`、`config/competition.yaml` 的 `scoring.*_subjective_weight` |
| 演示数据 | `competition/management/commands/seed_demo.py`（生成 / `--clear` 清理） |
| 提交与确认 | `competition/services/submissions.py`、`competition/views/student.py` |
| 导出 | `competition/services/export.py` |
| 测试 | `tests/`，43 个用例，`manage.py test tests -v 2` |

> 里面按「改 τ / 改 σ / 换参考图 / 加新指标 / 换整个任务的图」五种情况各写了步骤。

## 五、几点说明（也写在 README 第十章）

- 平台只能评价**结果图像质量**，无法验证算法原创性、效率与可复现性。
- 去色客观指标是公开 MATLAB 代码的移植，适合同一平台内横向比较，不宜与论文绝对数值逐位对齐。
- CADIK24 与 SIDD 均为公开数据集，若要正式计分，建议至少换一张教师自备、未公开的参考图。
- 参考图存放在服务器 `data/private/`，无任何 URL 映射，直接访问返回 404（可当场验证）。
- 仓库里不含 `.env`、数据库、学生名单与真值图，`git pull` 不会覆盖运行数据。
